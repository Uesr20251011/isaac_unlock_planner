# 以撒多来源总榜：加权公式与试算 v1

日期：2026-11-04。目标是得到可重算的道具综合强度分、总排名和分级，服务后续全角色打标。已完成718项试算、13项模型检查及13种敏感性情景。以下是可审计的工程默认方案，不声称在没有真实通关结果标签时找到了统计意义上唯一最优的权重。

## 结论

推荐使用**来源去重、版本折扣、每来源每道具影响上限约束的成对偏好模型**。先记录各榜实际支持的“A强于B”，再拟合统一分数。与简单加权平均名次相比，它能处理局部榜、只分级的榜和未收录项；与只取多数票相比，它保留来源质量与版本适用程度。

现有719条原榜中，一条旧版Tonsil没有可靠的当前实体对应，不进入当前道具模型，仍作为来源附录保留。饰品、卡牌和起始装备升级不与收藏道具混用实体；它们没有被全榜收录不构成低分证据。剧情/路线道具须标记用途，低战斗位置不能解释为可以跳过其路线功能。

## 先统一比较口径

强度指道具入手后在正常单人流程中提供的通关帮助，兼顾输出、生存、资源和选择权。熟悉基本机制、可查资料；不默认无限刷时间或已经组成特定神组合。来源若只讨论某角色、模式或池，只提供该范围内的比较。

解锁成本、先开放哪条路线、每日等待和全成就门槛属于**解锁顺序**，不直接扣道具强度分。神性可以强度很高而解锁顺序靠后。旧开荒指南中的优先级颜色和本项目65项编辑综合意见，不作为新的独立强度选票；其机制与路线理由用于审核、版本修正和后续解锁安排。

## 公式

来源s对道具i、j：若实际把i排在j前，记 y(s,i,j)=1，反向为0。未共同评价则不建立比较。同一等级或相同站点分数未提供内部顺序时，暂不建立这两项之间的严格比较。本版不把“同等级”误解为实力精确相等，也没有拟合并列概率参数。

对有逐道具投票记录的来源，使用来源级饱和系数：

    h(n) = sqrt(n / (n + 50))
    H(s) = median(h(n(s,i)))，只取有效、正记录数的道具

50是工程上的半饱和参数，需测试25、50、100，不能冒充独立投票人数的统计估计。明确0票的道具不提供该来源比较；0分不一定是0票，必须核查。个人榜或未公布记录数的来源，H取1，其证据局限由q及来源说明记录，不能假称人数相同。这里的记录数只作为可靠程度代理，不从站点记录推导游戏胜率或置信区间。

为什么采用来源级H：逐道具记录数进入每对权重，再加统一正则，会把低曝光的榜首向中间压缩，甚至在只有一张完整榜时改变它的顺序。这个现象已经由构造案例及原榜实测确认。改用来源中位曝光只影响这张榜整体的可信权重，不把“被评价更多”变成强度优势。逐道具票数继续保留在原始数据中，0票仍不参评。本次单独运行Unduel时，718项相对原始顺序改变数为0。

来源s的初始成对权重：

    coverage(s) = sqrt((实际可比较道具数−1)/(总榜道具数−1))
    raw_w(s,i,j) = b(s) × q(s) × r(s) × H(s) × coverage(s)
                   × sqrt(v(s,i) × v(s,j))
                   / max(d(s,i), d(s,j))

- q：来源可核验程度，0到1。原作者、原始条目、方法/理由是否可读，按预先声明的规则打分，不根据“是否符合我的喜好”打分。
- b：可调的来源基础系数，默认1，敏感性检查取0.75、1.25；它不改变来源原本的质量标记。
- r：与当前强度目标的匹配程度。入手后常规流程强度为1；单纯解锁先后、游戏质量0–4、未读到实际评级的标题不进入模型。
- v：逐道具版本适用程度。建议1=已核对目标补丁；0.85=明确忏悔+但未逐项核对；0.6=忏悔或补丁不明；0.3=已知相关机制大改而仅剩旧意见；0=不可对应/不适用。需保留修正依据。
- d：该来源实际与此道具比较的其他道具数。对全榜为N−1；分级时只数跨级比较。这防止把一张719道具榜展开成25万对比较后冒充25万个独立样本。
- coverage：限制局部意见被放大到整个总榜。只读到12件天使池S级的顺序不能领取全量榜的影响预算。平方根折扣是预先声明的工程选择，另用线性折扣作敏感性对照；不声称是实战数据学出的最优指数。

同一作者、转载、翻译、站内子榜归入同一family。先去掉被同源更完整、质量/版本不低的榜单完全包含，且没有提供新比较的派生视图，避免重复摘录改变票重。仍有新增或冲突意见的同源子榜，每对只取预先权重最高的有效证据；相同权重优先较新版本。合并后再缩放，使该family对任何一个道具的总比较权重不超过其预算 B=max(b×q×r×H×coverage)：

    M(g,i) = sum_j selected_w(g,i,j)
    w(g,i,j) = selected_w(g,i,j)
               / max(1, M(g,i)/B(g), M(g,j)/B(g))

随后求潜在强度theta：

    P(i优于j) = sigmoid(theta_i - theta_j)

    最小化 L(theta) = sum_g sum_(i<j,已比较) w(g,i,j) ×
                      [log(1+exp(theta_i-theta_j))
                       - y(g,i,j)×(theta_i-theta_j)]
                      + lambda/2 × sum_i theta_i²

默认lambda=0.03，并检查0.01、0.03、0.1。正则使只有单向意见的道具也得到有限数值，避免极端“无穷强”；它是稳定化设计，不能当额外玩家评价。

展示总分：

    总分_i = 100/(N−1) × sum_(j!=i) sigmoid(theta_i-theta_j)

按未四舍五入的theta/总分排序。总分表示模型对本次候选集合中其他道具的综合相对偏好，**不是通关率、伤害百分比或道具间的倍率**。展示一位小数；数值相近时标记相近，不用小数制造确定性。计算结果相同（theta数值误差1e−8以内）的道具共用名次区间和中位名次，不以输入顺序拆开。

## 总分级

只有名次或主观等级的输入不能辨识绝对的“单拿就能通关”界线。第一版建议明确叫**相对强度等级**，按最终名次的百分位分组：

| 等级 | 最终相对位置 |
|---|---|
| S | 前5% |
| A | 接下来15%（累计前20%） |
| B | 接下来25%（累计前45%） |
| C | 接下来25%（累计前70%） |
| D | 接下来20%（累计前90%） |
| F | 后10% |

这是用户已经选择的相对位置方案，不宣称游戏天然有这个比例的S级道具。实施时使用p=(名次−1)/(N−1)，各边界允许整数舍入；718项对应S36、A108、B179、C179、D144、F72项。若精确并列横跨边界，显示“S/A边界”等并保留共同名次区间，不强行凑比例。若以后采用“无条件带飞/强但有条件”等绝对语义，需要额外固定强度锚点与逐项复核。

## 稳定性与可信度

同时报告：有效来源family数、来源覆盖、单来源标记、分歧、逐family权重上下浮动25%的名次范围、逐一移除family后的范围、正则/曝光/覆盖参数调整后的范围、分级在这些情景中的保持率。这里是**敏感性范围，不是95%统计置信区间**；不同网站的参与者可能重叠，也不假设榜内25万对比较相互独立。保持率只是选定13种情景的描述，不能解释为“S级有92%的概率”。

单来源条目可给试算分和名次，但不能声称得到多来源共识。移除某来源后不再覆盖/连通的道具，不从正则项强行推导“新排名”，应记为失去可比证据。跨范围没有重叠连接的子榜须分开，不能只依赖先验拼成全榜。

已检查：版本一致的完整单榜保序（包含逐项记录数差异极大的案例）、复制同源与摘录子榜不增权、局部榜不评价圈外道具、同级不虚构内部顺序、并列边界不强行拆分、版本0不参与、梯度数值核对、收敛、来源逐项映射、留一来源敏感性。逐项版本修正若不同，属于明确的信息折扣，不能再无条件承诺原榜保序。

## 方法参考

- [PlackettLuce作者文档](https://hturner.github.io/PlackettLuce/articles/Overview.html)：模型可处理部分排名与并列，弱连接或单向意见需要稳定化；本稿的加权与工程参数为自行设计，并非该包的默认实现。
- [Newman 2023，Efficient Computation of Rankings from Pairwise Comparisons](https://jmlr.org/papers/v24/22-1086.html)：成对比较的Bradley–Terry排名建模。
- [Dupas等，Aggregating Partial Rankings from Neighbors](https://www.nber.org/papers/w29911)：比较集合不同时，直接平均名次可能误排，成对方法需要研究具体条件。

实际纳入数据、参数、试算结果和覆盖限制另见同目录的inputs、results、audit文件。公开资料未提供可用于学习最优权重的全角色实测通关数据，因此不使用“机器学习已证明最中肯”之类表述。
